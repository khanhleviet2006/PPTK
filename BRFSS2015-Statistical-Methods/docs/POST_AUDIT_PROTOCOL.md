# Post-audit execution design

This is a post-audit exploratory extension informed by the previously disclosed2015 test. It is not a retroactive public preregistration. Configuration and plans were serialized before candidate fits. All old2015 final-test IDs are excluded from predictive development. QUICK fixed budget2000, two outer stratified folds, inner2 folds for threshold/search; fixed primary BA. STANDARD uses all eligible development rows/five outer folds; long full-budget runs remain unexecuted.

The finite78-configuration grid stages feature screening, models, imbalance, ensembles, small randomized search and calibration rather than a Cartesian explosion. Feature k refers to encoded columns/PCA components; RFECV chooses its own count. RFECV/permutation v4 use deterministic codebook expansion and inner-fitted imputer/scaler; source-specific earlier runs are preserved. Synthetic sampling on continuous-only representation is compared with continuous-only controls; mixed full representation uses SMOTENC. Vanilla ADASYN is never applied to integer-coded nominal variables. Threshold curves are descriptive, not clinical operating constraints.

CV candidate choice and development reporting remain exploratory after selection. Uncertainty over training/model selection is not supplied by respondent bootstraps. Calibration is fitted only inside outer training with complete pipelines. Stacking includes complete fold-local base pipelines and out-of-fold meta-features. Hard-voting pseudo-probabilities are not calibrated probability forecasts.

A separate14-variable temporal LR track selected among three prespecified LR policies by2015 CV, froze model/threshold before2017 row outcomes, and evaluated a fixed random sample5000 once. This temporal model predates subsequent RFECV/permutation software corrections, does not use those selectors, and was not refitted or reevaluated afterward. The2017 result cannot now be used for tuning. No comparison of the78-candidate development winner against this independently evaluated14-variable model is valid as an architecture experiment.

Full2015 survey-domain descriptive estimates, including respondents belonging to the legacy holdout, answer a separate inference objective. These results do not select predictive models or thresholds and are not a repeated predictive test evaluation. Gene/laboratory data are unavailable. Federated optimization is simulated on public development partitions with centralized preprocessing and no privacy guarantee. UCI processed source cannot currently be linked to exclude old holdout respondents; predictive reproduction is deliberately blocked, not silently repartitioned.

Software history: v1 had one feature-name export failure; v2 completed but inner ranking preprocessing needed stronger isolation; v3 attempted that isolation but hit a nested-pipeline wrapper validation error; v4 uses the compatible sklearn pipeline and is the canonical corrected run. Earlier engine bytes are archived with verified hashes. No historical failure is converted into a success claim.
