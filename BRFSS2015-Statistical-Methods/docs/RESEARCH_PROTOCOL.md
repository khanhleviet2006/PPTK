# Prespecified research protocol, version 1

Registered within this repository before real-data prediction evaluation; not a public preregistration. Course: Statistical Methods. Cross-sectional self-report supports associational interpretation only.

RQ1 tests whether demographic, biomedical, social and behavioral variables are associated with self-reported diabetes after mutual adjustment. Primary null hypotheses are that each prespecified coefficient equals zero (OR=1), with grouped joint Wald tests preferred for multi-level factors. Primary estimands are survey population prevalence in eligible respondents and conditional adjusted prevalence odds ratios. These are not incidence risk ratios. The target population is noninstitutionalized adults represented by the 50-state/DC BRFSS 2015 combined landline/cellular sample; territories are excluded via a domain indicator, retaining the entire design for variance.

The primary outcome compares DIABETE3=1 (yes) against 3 (explicit no). Exclude pregnancy-only (2), borderline (4), unknown (7), refused (9), and missing. This is a diagnosis contrast conditional on these exclusions, NOT overall diabetes prevalence among every adult. Separately report the original code frequencies. Sensitivity: include borderline as non-diabetes. Secondary core three-category outcome maps 3/4/1 to 0/1/2, with the first category named 'no diabetes reported', not 'confirmed no prediabetes'. No disease type is inferred. PREDIAB1 is an optional module with structured nonparticipation: its negatives must be explicit 3, never a missing value. The optional-module implementation is available at the mapping level, but nationwide module inference is blocked pending a state/version-specific eligibility/weight manifest. See CDC module participation links in the data dictionary.

RQ2 compares training-only feature selection, class weighting, SMOTENC and undersampling. RQ3 compares the selected model with a prespecified unweighted logistic prediction comparator on identical held-out respondents. Primary predictive endpoint: balanced accuracy at a training-OOF-selected threshold. Null for a paired improvement contrast: balanced-accuracy difference =0. Secondary endpoints: sensitivity, specificity, macro-F1, precision, ordinary accuracy, probability ROC-AUC, average precision (PR-AUC), Brier and log loss. For three classes, balanced accuracy equals mean class sensitivity; report all class-specific errors. All effects are reported with precision, regardless of a 0.05 threshold.

RQ4 examines descriptive test subgroup performance by recorded sex, race/ethnicity and age group, and missing-data/outcome sensitivities. No claims of subgroup equivalence or fairness follow from nonsignificant comparisons. Small groups are suppressed below 30 test observations. Subgroup predictive intervals are conditional respondent bootstrap intervals, not population survey-design intervals.

The prediction estimand is performance for respondents from the same eligible sample distribution. The sampling weights are used for secondary point estimates only; the primary predictive analysis is unweighted and its bootstrap is not advertised as survey population uncertainty. Primary inference does use survey weights and complex design variance. No direct quantitative improvement claim against Chang is allowed without resolving cohort/outcome contradictions and reproducing its evaluation. An 82.26% accuracy target is descriptive motivation, never a success gate.

Execution profiles and the finite experiment list are fixed before final test access. No test-directed revisions are permitted in an existing run. Synthetic validation uses distinct directories and is never population evidence. A software change invalidates run signatures; software corrections after real test access must be disclosed and any new split on overlapping respondents is not automatically a fresh untouched evaluation. Final reports must state this if it occurs.
