# Prediction experiment plan

Split eligible original-data respondents 80/20 with fixed seed 2015, stratifying outcome. Unique identifier is (_STATE,SEQNO). Preserve respondent IDs, test-ID hash and cohort hash. Survey design metadata, outcome-derived questions, DIABAGE2, INSULIN, PREDIAB1 and other diabetes modules are excluded from predictors. Transform source codes deterministically before splitting; all learned transformations occur inside CV.

Quick profile: 3 folds; up to 4,000 training respondents; all available model families, ensembles, original features. A limited set of feature/imbalance ablations is also run. This is a runtime/implementation check, not a final full-data experiment. Standard: 5 folds, all training data, full finite feature ablations and imbalance strategies, 1,000 bootstrap replicates. Extended: standard plus fixed extra hyperparameter candidates and 2,000 replicates. CPU defaults use one worker per estimator to control memory. Optional boosters have a separate pinned requirements file; missing libraries produce explicit SKIPPED records. GPU is optional through user-supplied model adaptation; CPU is the tested default.

Compare LR, decision tree, RF, Extra Trees, histogram gradient boosting, XGBoost, LightGBM, CatBoost, feature ensemble, soft voting and stacking. A feature ensemble averages predictions from clinical-only LR, mutual-information-selected Extra Trees and all-feature boosting. Stacking uses complete base pipelines inside inner CV, so meta-training rows do not influence base preprocessing fits. This extra cost is justified by out-of-fold meta-features; compare performance before making an ensemble contribution claim.

Selection: largest mean validation-fold balanced accuracy; lexical experiment hash breaks exact ties. Threshold grid 0.20–0.80 is evaluated only on training OOF probabilities for binary outcomes; multiclass uses argmax. This double use of OOF predictions makes development scores optimistic for the selected strategy; untouched test results provide the final estimate. No t-tests treat dependent fold scores as independent samples.

Ablations compare original, clinically motivated groups, MI, L1 coefficient ranking, Extra Trees ranking, training-inner-validation permutation ranking, RFE, and domain interactions (BMI squared, BMI-by-age-category score, total unhealthy days). Top-k=5/10/15/20 refers to ENCODED model columns, not 5/10/15/20 distinct original variables. Standard scaling and one-hot encoding are inside folds. MI treats the post-encoding matrix as continuous; use results as empirical rankings and note that treatment of discrete columns can affect the estimator.

Imbalance: none, balanced class weights, random undersampling, SMOTENC for mixed variables (impute raw codes then resample then one-hot encode). SMOTE/BorderlineSMOTE only for genuinely continuous-only representations. BorderlineSMOTE is deliberately ineligible for this primary mixed data feature set; do not synthesize fractional sex/race categories. Continuous resampling is not used to infer epidemiological associations.

Each completed experiment caches OOF predictions and checksums. CV indices and development logs are preserved. After selection, freeze and hash the final fitted candidate and same-cohort logistic comparator. Perform one batch test evaluation. Paired respondent bootstrap estimates differences conditional on these fixed fitted models. One prespecified binary McNemar comparison supplements point estimates; do not infer significance from non-overlapping model confidence intervals. Additional comparisons require Holm correction and documentation. Calibration curves, Brier/log loss and subgroup errors complement discrimination. Clinical thresholds require external utility validation.

Processed Dataset B reproduction is a separate explicit command requiring a provenance JSON. It is labelled approximate because Chang's sample size, outcome descriptions and processing order cannot all be resolved. Do not copy its numerical results into empirical artifacts. Original-population survey inference never uses Dataset B.
