# Statistical analysis plan

Descriptive Table 1 reports raw n, weighted means/proportions, 95% intervals, and missing counts/weighted fractions overall and by outcome. Group comparisons use univariate survey logistic regressions; these are descriptive associations and use the same design variance as the adjusted model. Hypotheses for categorical factors concern a joint set of coefficients; coefficient-level BH q-values are exploratory and include all reported terms. There is no multiplicity-adjusted confirmatory discovery claim.

Prespecify all 19 predictors in variables.yaml; categorical factors use their lowest valid observed code as reference (fixed codebook category ordering), BMI and unhealthy days are scaled per 10 units. Nutrition and alcohol use scale raw implied decimals by 0.01. Age is categorical, not a fictitious exact age. Sex is the survey-recorded binary variable, not gender identity. Race is the CDC calculated race/ethnicity factor. Blood pressure/cholesterol are reported diagnoses rather than measured concentrations. General health and healthcare use may follow diabetes; including them answers a mutually adjusted association question, not a causal effect question.

Use complete cases for primary adjusted inference; this estimates a conditional association in the complete-case analysis domain under stronger selection assumptions. Median/mode imputation is an explicitly limited deterministic sensitivity, not proper multiple imputation and not a remedy for MNAR. Outcome and survey-design fields are never imputed. Missingness is reported by outcome; no test proves MAR.

The survey engine implements an ultimate-cluster, with-replacement Taylor linearization without FPC. For a ratio mean, respondent influence is w_i*(x_i-p)/sum_domain(w). Sum influence inside each nested (stratum, PSU). Within stratum h with m_h PSUs the covariance contribution is m_h/(m_h-1) times the centered PSU cross product. Retain zero-score PSUs outside each analysis domain. Lonely strata stop execution. Weights are treated as fixed; calibration-specific variance reductions are not modeled.

Binary logistic: solve weighted binomial pseudo-score equations with normalized weights; sandwich covariance is inverse information times stratified PSU score covariance times inverse information. Normalizing weights changes neither coefficients nor covariance. Use t confidence intervals with design df minus model rank plus one; joint tests use an F reference with design residual df. Compare binary coefficients, covariance, means and domain variance numerically to R survey::svyglm / svymean. Ordinary freq-weight GLM standard errors are discarded. Multinomial regression uses baseline-category softmax pseudo-likelihood, analytical score/Hessian and identical design aggregation. RRR=exp(beta); test recovery on known synthetic coefficients and compare weighted softmax coefficients against VGAM where available. Multinomial coefficients and covariance are also compared against an independently fitted R nnet model, numerical Hessian and survey::svyrecvar score aggregation.

Diagnostics: convergence, gradient tolerance, matrix rank, condition number, large coefficients, VIF and confidence intervals. Fail on singular inference designs and insufficient design df. Inspect broad intervals/separation; no automatic coefficient dropping to manufacture results. Continuous logit linearity is a model assumption; prespecified prediction interactions do not validate inferential functional forms. Run spline/nonlinearity sensitivity before publication if material curvature appears. Binary and core-three analyses use separate run directories. Do not classify a null result as proof of no relationship.
